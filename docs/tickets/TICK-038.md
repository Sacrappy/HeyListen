# TICK-038 — Cut resource use (RAM, VRAM, CPU, GPU) without losing quality or fps  · model: Opus · after TICK-033
**Why**: user, 2026-11-10: the Switch 2 runs this game in ~9 GB of 12 GB shared LPDDR5X; we use far more (castle-move VRAM peak 8.6 GB after TICK-031, plus process RAM: guest memory, mirrors, shadows, captures, lifted code, caches). Lower use also helps 8 GB cards and laptops.
**Goal**: measure per-category use at the Market and Hyrule (process private bytes / working set, VRAM by kind: textures, mirrors, shadows, render targets, staging, pipelines; CPU threads busy-waiting or spinning; GPU idle/bubble work), then remove waste: duplicate copies (guest + mirror + shadow), oversized pools/staging rings, idle spinning threads, redundant passes, caches never read. Each change behind a switch; picture and fps unchanged (shots + bench).
**Acceptance**: before/after table per category; total RAM+VRAM reduced measurably; no fps/1% low loss beyond spread; picture identical.
**Branch**: `feature/TICK-038-resources`

**Result (2026-11-10)**: measured per category (engine/docs/perf-audit.md "TICK-038"): of the 14.2 GB working set standing at the Market, 7.75 GB is the game's memory and 5.0 GB the NVIDIA driver's arenas, filled at start by the precompile's 7808 compute pipelines (every texture variant; the Market binds ~110) and their modules. Changes: compute programs stay on disk until first dispatched when the pipeline cache is warm (`RX_VK_LAZY_COMPUTE`, default 1; 0 = as before), compute shader modules let go once their pipeline exists (`RX_VK_CS_MODULE_DROP`, default 1). Working set -1.9 to -2.3 GB (kokiri-idle 14.20 -> 11.90, castle-move 15.51 -> 13.59, hyrule-walk 14.85 -> 12.98 GB), private -2.0 to -2.5 GB, driver VRAM -120 to -190 MB, start-up shaders 8.5 -> 2.8 s. fps / 1% low: kokiri-idle 69.7 / 30.7 -> 71.4 / 35.2, castle-move 66.6 / 26.3 -> 66.2 / 26.7 (5 runs each, within spread), hyrule-walk 65.2 / 17.9 -> 66.1 / 27.2. Picture: same in shots. Capture-spare aging tried (`RX_VK_CAP_SPARE_AGE`, off: no steady gain, more buffers made). Accounting log `RX_VK_RES_LOG=1`, sampler `tools/bench/ressample.py`. Shaders not re-prepared. Total VRAM unchanged within noise; next: the pipeline cache object (~1 GB), unused graphics pipelines, kept render targets.
