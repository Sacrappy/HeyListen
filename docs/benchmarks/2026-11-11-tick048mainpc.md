## Decision: not on everywhere; the default follows the PCIe link
`gpu/vk/vk_memory.cpp` `pcie_link_gbps()`: `nvml.dll` (NVIDIA driver) gives the card's maximum link generation and width (the current link is throttled at idle, so the maximum is read). `RX_VK_MSYNC_DIFF` unset: on when the maximum is <= 8 GB/s (PC 3050's Gen3 x4 = 3.9; Gen4 x4 and Gen3 x8 = 7.9 also on), off when wider or when NVML is missing (other vendors, integrated GPUs). An explicit `RX_VK_MSYNC_DIFF` still wins. The log shows `PCIe link maximum Gen5 x16 (63.0 GB/s)` and `chunk diff off by default`. Here it reads Gen5 x16 and the diff is off. Not tested on PC 3050 (not touched): there NVML should read Gen3 x4 and keep the diff on; if NVML is missing there it would be off.
