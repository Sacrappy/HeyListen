# TICK-051 benchmark: frame-time spikes on PC 3050 (2026-11-11)

Machine: PC 3050 (i5-10400F 6C/12T, 32 GB, RTX 3050 8 GB on PCIe 3.0 x4, Windows). Market save (`user-save-backup`), windowed,
`--fps-limit 360`, frame generation off. `scripts/pcbench51.py` (pcbench.py + the frame trace moved into the run folder) through
`ab51.py` (interleaved rounds, the order reversed in even rounds), 110 s runs, 66 s cut (the scene is reached 50-62 s after launch).
exe: TICK-045's (`builds/tick045`), the lifted game, equal to main's. dll built on PC 3050 with llvm-mingw (`RX_VK_ONLY`, x86-64-v3)
as TICK-048. Every run: save identical to the backup after it, no game left running.

Metrics: fps, 1% low, p99 from `bench.json` (the game's present trace); spikes = frames of `hookshot_frames.csv` after the cut over
2x that run's median (`tools/bench/spikes.py`); frames over 50 ms from the same trace.

## Builds
- `builds/main1bb`: TICK-045 exe + main 1bb7136's dll (the base asked for at the start).
- `builds/mainb17`: TICK-045 exe + main b17b933's dll (main moved during the ticket).
- `t51a`/`t51b`: 1bb7136 + the trace; `t51c`: + batch (off) and the pass-timing span; `t51d`: + an eviction switch (dropped);
  `t51e`: + the BC cache (off); `t51f`: rebased on b17b933, batch and cache on by default (the adopted build).
